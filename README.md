# Funniest Forecast for a City That Isn't

Entry for the [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-funniest-forecast-for-a-city-2a8769cf): one line, at most 120 characters, the funniest weather forecast for a city that does not exist.

`main.py` writes the forecast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## The forecast

> Kettlebury: heavy rain, 11°C, expect localized flooding of the library and a 100% chance the ducks know why.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
